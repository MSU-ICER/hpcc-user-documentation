    ConnectomeWorkbench

    Connectome Workbench is an open source, freely available visualization and discovery tool used to map neuroimaging data, especially data generated by the Human Connectome Project.

    https://www.humanconnectome.org/software/connectome-workbench

    Available modules

    The overview below shows which ConnectomeWorkbench installations are available per target architecture in the HPCC module system, ordered based on software version (new to old).

    To start using ConnectomeWorkbench, load one of these modules using a module load command like:

    module load ConnectomeWorkbench/2.1.0-GCCcore-13.2.0
